* 01 Elementarne zasady zapisu rekordów w formacie JSON

JSON (JavaScript Object Notation) to tekstowy format zapisu i wymiany danych.

1. Rekord informacji zapisuje się w nawiasach:
   - klamrowych: { ... }
   - prostokątnych: [ ... ] lub {"klucz": [...]} lub nawet {"":[...]};
2. Nazwa pola rekordu, inaczej klucz, zapisuje się tekstem ujętym w podwójnych cudzysłowach;
3. Poprawnymi wartościami pól rekordów są:

   Typ                  Przykład
   -----------------------------------------------------------------------------
   Tekst             "czujnik", "2026-11-07"   # datę zapisuje się jako tekst
   Liczba            42, 21.5, -3              # Jako sep. używa się znaku '.'
   Wartość logiczna  true, false               # pisane tylko małą literą !!!
   Pusta wartość     null                      # null oznacza brak danych
   Obiekt            {"miasto": "Warszawa"}   # obiekty mogą zawierać inne ob.
   Tablica           [1, 2, 3]                 # tabele mogą zawierać dowolne ob.

4. Pola oddziela się przecinkiem, ale ostatnie pole nie jest nim zakończone;

** Przykład zapisu obiektu JSON

{
  "imie": "Ala",
  "wiek": 28,
  "aktywny": true,
  "zainteresowania": ["muzyka", "podróże"]
  "adres": {
        "ulica": "Rubinowa",
        "numer domu": 3,
        "mieszkanie": null,
        "kod pocztowy": 20-575
        "aktualny": true
        }
}

* 03 JSONata - wyrażenie obliczeniowe, filtrujące, przekształcające i generujące dane;

JSONata, to jest to język wyrażeń wykorzystywany do odczytywania i przekształcania danych zapianych w formacie JSON. Zastosowania:

- służy do wyszukiwania i przekształcania danych JSON;
- pozwala wybierać pola, filtrować tablice i wykonywać obliczenia agregujące dane numeryczne;
- umożliwia tworzenie nowej struktury JSON z danych wejściowych;
- ma zwięzłą składnię oraz wiele wbudowanych funkcji operujących na danych;
- jest szczególnie użyteczny do przekształcania wiadomości w systemie node-red (zamiast jawnego definiowania funkcji w systemie node-red);
- ma wiele implementacji w popularnych językach programowania (np. https://github.com/rayokota/jsonata-python)

Przykłady - patrz: https://try.jsonata.org/ oraz https://docs.jsonata.org/overview

** Komentarz do języka wyrażeń JSONata

W Node-RED, używając języka JSONata, można napisać blok kodu zawierający wiele instrukcji, zmienne i obliczenia.

Do utworzenia bloku używa się nawiasów okrągłych ( ), a poszczególne instrukcje oddziela się średnikami ;.

*** Podstawowy blok kodu

(
    $a := 10;
    $b := 20;
    $wynik := $a + $b;
    $wynik
)

Wynik: 30

Zasady:
- ( ) – początek i koniec bloku.
- := – przypisanie wartości do zmiennej.
- ; – oddzielenie instrukcji.
- Ostatnie wyrażenie – wartość zwracana przez cały blok.

Przykład w Node-RED

Załóżmy, że msg.payload zawiera:

{
    "temperatura": 25,
    "wilgotnosc": 60
}

W węźle Change ustaw typ wartości na expression (JSONata) i wpisz:

(
    $temp := payload.temperatura;
    $wilg := payload.wilgotnosc;

    $status := $temp > 30 ? "GORACO" : "OK";

    {
        "temperatura": $temp,
        "wilgotnosc": $wilg,
        "status": $status
    }
)

Wynik:

{
    "temperatura": 25,
    "wilgotnosc": 60,
    "status": "OK"
}

***  Definiowanie własnych funkcji w bloku

Możesz również tworzyć funkcje:

(
    $dodaj := function($a, $b) {
        $a + $b
    };

    $wynik := $dodaj(10, 20);

    $wynik
)

Wynik: 30

***  Warunki w bloku

JSONata nie posiada klasycznej instrukcji if z JavaScript. Zamiast tego używa operatora ? :.

(
    $x := payload;

    $wynik := $x > 100 ? "DUZO" :
              $x > 50  ? "SREDNIO" :
                         "MALO";

    $wynik
)

***  Ważne ograniczenia

JSONata nie jest JavaScriptem, dlatego:

JavaScript: { ... } – blok kodu
JSONata: ( ... ) – blok wyrażeń

JavaScript: let x = 10
JSONata: $x := 10

JavaScript: if / else
JSONata: ? :

JavaScript: function(a) { ... }
JSONata: function($a) { ... }

JavaScript: return x
JSONata: Ostatnie wyrażenie

JavaScript: for, while
JSONata: $map(), $filter(), $reduce()

W Node-RED można umieścić cały program JSONata w jednym polu expression w węźle Change. Nie jest konieczne używanie węzła Function, jeśli program wymaga jedynie transformacji danych, wykonywania elementarnych obliczeń lub sprawdzania warunków.

* 04 Pomocne uwagi dotyczące przetwarzania danych

** Filtracja danych

Jeżeli obiekty JSON zawierają powtarzającą się strukturę danych, możliwe jest ich filtrowanie, a następnie agregacja, np. main.temp - zgrupuje wszystkie wartości numeryczne z pól 'temp' z obiektów 'main'. Po tej selekcji możliwe jest wykonanie obliczeń z wykorzystaniem funkcji JSONata.

$count(main.temp)                   # obliczy liczbę wartości numerycznych
$sum(main.temp)/$count(main.temp)   # obliczy średnią;

Selekcja obiektu po wartości jednego z pól - do elementów tablicy można odwołać się na kilka sposobów:

$[numer elementu] lub ...
$[obiekt.klucz = wartość szukana parametru odpowiadającego kluczowi]

** Odwołanie do kontekstu wiadomości i całego dokumentu

W JSONata zmienne zaczynają się od '$', a wartość przypisuje się operatorem ':='.

Przykład w Node-RED - gdy dane są w msg.payload

(
  $temperatura := payload.temperature;
  $temperatura > 25 ? "ciepło" : "chłodno"
)

Nawiasy tworzą blok; po przypisaniu zmienna jest dostępna w dalszej części tego bloku. Istnieją też zmienne wbudowane: $ oznacza bieżący kontekst, a $$ — korzeń danych wejściowych.

W tym przykładzie $temperatura jest zdefiniowana tylko i wyłącznie na potrzeby bloku obliczeń.

* 05 Funkcja 'filter' - prezentacja - https://docs.jsonata.org/higher-order-functions

Sygnatura $filter(array, function), gdzie: function(value [, index [, array]])

Zwraca tablicę pierwotnych elementów, które spełniają warunek opisany przez definicję funkcji 'function':

function(value [, index [, array]]), gdzie:

value - wartość przekazywanego elementu (od 0 do n-1);
index - wartość bieżącego elementu;
array - oryginalna tablica elementów;

Argumenty ujęte w nawiasy kwadratowe są opcjonalne.

przykład:

$filter($, function($v) { $v.main.temp > 10})

$filter(Account.Order.Product, function($v, $i, $a) {
  $v.Price > $average($a.Price)
})

* 06 Funkcja 'map' - prezentacja - https://docs.jsonata.org/higher-order-functions

Sygnatura: $map(array, function)

Zwraca tablicę wartości, której każdy z elementów pierwotnej tablicy 'array' jest przekształcony/obliczany na podstawie definicji funkcji:

function(value [, index [, array]]), gdzie:

value - wartość przekazywanego elementu (od 0 do n-1);
index - wartość bieżącego elementu;
array - oryginalna tablica elementów;

Argumenty ujęte w nawiasy kwadratowe są opcjonalne.

Przykłady:

$map([1,2,3], function($v) { $v * 2 })
wynik: [ 2, 4, 6 ]

$map([2], function($v) { $v * 2 })
wynik: [4]

"Email": {
        "address": [
                fred.smith@my-work.com",
                fsmith@my-work.com",
                freddy@my-social.com",
                frederic.smith@very-serious.com"
        ]
}

$map(Email.address, function($v, $i, $a) {
   'Item ' & ($i+1) & ' of ' & $count($a) & ': ' & $v
})
wynik:
[
  "Item 1 of 4: fred.smith@my-work.com",
  "Item 2 of 4: fsmith@my-work.com",
  "Item 3 of 4: freddy@my-social.com",
  "Item 4 of 4: frederic.smith@very-serious.com"
]
